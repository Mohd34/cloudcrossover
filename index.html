The 3 Hidden Cloud Cost Traps

Serverless calculators often omit the infrastructural side effects that drive 60–80% of unexpected cloud bills.

AWS NAT Gateway Tax

Private Subnet Egress

Placing AWS Lambda inside a VPC to access RDS or ElastiCache requires an AWS NAT Gateway for external API calls.

Fixed tax: $32.85/mo per AZ idle fee + $0.045/GB processed.

Impact on current workload: $32.85/mo
API Gateway Multiplier

REST vs HTTP API Gateway

Legacy AWS REST API Gateways charge $3.50 per million calls. Migrating to HTTP API Gateway drops this to $1.00/M. Fixed VPS instances charge $0 for API routing.

Current REST penalty: +$25.00/mo
Bandwidth Extortion

Data Egress Markups

AWS charges $0.09/GB for public egress. Hetzner includes 20,000 GB free (€1.10/TB overage). DigitalOcean includes 1,000–4,000 GB free ($0.01/GB overage).

AWS egress on current workload: $99.00/mo

Methodology & Frequently Asked Questions

How is the Crossover Point (R*) computed?

We model the total marginal cost per request: \(c_{\text{req}} = (\text{duration} \times \text{memory} \times \text{rate}_{\text{arch}}) + \text{rate}_{\text{invoke}} + \text{rate}_{\text{gateway}}\). The break-even point R* is calculated by solving where the cumulative serverless bill equals the fixed monthly fee of a VPS instance, accounting for AWS free tiers.

Does this account for developer maintenance hours?

Serverless eliminates Linux patching and OS administration. However, modern deployment tools like Kamal, Coolify, and Docker Compose have reduced VPS maintenance to minutes per month, making the financial savings of VPS compelling past 2M–5M requests.

Why does AWS Lambda get expensive so fast?

Invocations and compute are cheap in isolation, but combined with API Gateway ($1.00–$3.50/M) and data egress ($0.09/GB), high-volume workloads pay a recurring tax on every single packet. A $4 VPS can easily handle 500 requests per second with nginx or Go.

What about cold starts and latency?

Serverless runtimes incur 100ms–2000ms cold starts when scaling from zero or after idle periods. VPS and container instances remain warm 24/7, providing consistent sub-5ms internal response latencies.
