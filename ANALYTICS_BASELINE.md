# 📊 CloudCrossover Analytics Baseline & Metrics Framework

## Baseline Zero Policy

In strict adherence to project rules:
- **No synthetic Lighthouse metrics are passed off as SEO traffic.**
- **No manual searches are recorded as organic rankings.**
- **All telemetry starts at absolute zero.**
- **Never claim user adoption until verifiable external events take place.**

## 2. Key Performance Indicators (KPIs) to Track

1. **Distribution / Viral Rate (PR Shares):**
   - Frequency of users copying Markdown PR tables and Reddit discussion snippets.
2. **Organic Referral Traffic:**
   - Inbound sessions from GitHub, Reddit (`r/devops`, `r/aws`), Hacker News, and technical blogs.
3. **ADR Adoption:**
   - Count of engineering teams downloading `0001-compute-platform-selection.md` files.
4. **Organic Search Indexing:**
   - Transition from `Submitted` → `Indexed` in Google Search Console for `index.html` and `crossover-guide.html`.
